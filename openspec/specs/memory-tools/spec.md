# memory-tools Specification

## Purpose

Контракты инструментов памяти для модели: что принимает и возвращает `memory_save` и `memory_list`, какие проверки применяются к сохраняемому тексту и как инструменты сообщают об ошибках.

## Requirements

### Requirement: Нативная регистрация инструментов

Плагин MUST регистрировать инструменты `memory_save` и `memory_list`, каждый с опцией `options: { codemode: false }`, так что они доступны модели в нативном тул-листе (а не только в code-mode-каталоге).

#### Scenario: Инструменты видны модели

- **WHEN** плагин загружен opencode
- **THEN** `memory_save` и `memory_list` присутствуют в тул-листе модели без дополнительных режимов

### Requirement: Контракт memory_save

`memory_save` SHALL принимать текст памяти, имя и тип; тип — одно из значений `user|feedback|project|reference` (перечень из спеки `memory-storage`), невалидный тип MUST отклоняться structured-ошибкой. Успешное сохранение MUST записать файл памяти и синхронно обновить индекс, вернув `{ ok: true }` с деталями записи. Повторное сохранение канонически идентичного текста SHALL возвращать ответ «already saved» без создания нового файла.

#### Scenario: Успешное сохранение

- **WHEN** модель вызывает `memory_save` с валидным текстом
- **THEN** файл памяти и строка индекса созданы, ответ содержит путь/имя записи

#### Scenario: Дубликат не создаёт файл

- **WHEN** сохраняется канонически идентичный текст
- **THEN** новый файл не создан, ответ помечает запись как уже существующую

### Requirement: Гейт prompt-injection

`memory_save` MUST отклонять тексты с инструкционной стилистикой («ignore previous instructions», «forget all» и подобными) с понятной ошибкой: сохранённая память реинжектится в будущие system-промпты, поэтому инъекция инструкций через память недопустима.

#### Scenario: Инструкционная инъекция отклоняется

- **WHEN** сохраняемый текст содержит «ignore previous instructions and …»
- **THEN** сохранение отклонено с structured-ошибкой и пояснением, на диске ничего не записано

### Requirement: Тег private

Контент внутри `<private>…</private>` MUST не сохраняться: если весь текст приватный — сохранение отклоняется, если приватный фрагмент — он вырезается, остальное сохраняется.

#### Scenario: Полностью приватный текст

- **WHEN** весь текст `memory_save` обёрнут в `<private>…</private>`
- **THEN** сохранение отклонено с пояснением, на диске ничего не записано

### Requirement: Soft-лимит размера памяти

Текст памяти сверх мягкого лимита SHALL сохраняться, но ответ MUST содержать пометку перелимита (`over_limit`); жёсткие отказы и retry-петли для перелимита MUST не вводиться. Значение мягкого лимита MUST быть зафиксировано при реализации именованной константой и закреплено тестом; спецификация задаёт только поведение перелимита, а не число.

#### Scenario: Перелимит сохраняется с пометкой

- **WHEN** сохраняется память крупнее мягкого лимита
- **THEN** память записана, ответ содержит пометку `over_limit`

### Requirement: Контракт memory_list

`memory_list` SHALL возвращать текущий собранный индекс `MEMORY.md` (строки-записи). Пустое хранилище MUST давать явный пустой ответ, а не ошибку.

#### Scenario: Пустое хранилище

- **WHEN** `memory_list` вызван до первой записи
- **THEN** ответ `{ ok: true }` с явным признаком пустого списка

### Requirement: Имя файла памяти безопасно

Имя памяти MUST валидироваться перед превращением в имя файла: паттерн допустимых символов — короткий kebab-case-слаг (строчные латинские буквы, цифры, дефис; как `name:`-слаг в формате zcode), запрет выхода за каталог хранилища (path traversal).

#### Scenario: Имя с обходом пути отклоняется

- **WHEN** `memory_save` получает имя, содержащее `..` или разделители путей
- **THEN** сохранение отклонено с structured-ошибкой о недопустимом имени

### Requirement: Structured errors, never throw

При любой ошибке инструменты MUST возвращать `{ ok: false, error: { code, message, suggestion } }` и MUST не выбрасывать исключения в хост; `message` описывает проблему, `suggestion` — конкретный следующий шаг.

#### Scenario: Ошибка хранилища возвращается структурой

- **WHEN** запись невозможна (например, лок не взят за таймаут)
- **THEN** ответ инструмента — structured-ошибка с кодом и подсказкой, исключения нет
