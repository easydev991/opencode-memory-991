# plugin-packaging Specification

## Purpose

Упаковка npm-пакета плагина памяти как дистрибутива: метаданные, по которым хост opencode распознаёт плагин; установка и обновление штатными командами хоста; ограничения на зависимости и сборку; соответствие пользовательской документации фактическому механизму установки.

## Requirements

### Requirement: Метаданные плагина v2

package.json пакета MUST содержать keyword `opencode-plugin` и server-entrypoint: сабпат `./server` в exports, указывающий на модуль с default-экспортом `{ id, setup }` (Promise plugin API v2). По этим метаданным хост распознаёт пакет как server-плагин при подключении.

#### Scenario: Хост подключает пакет как server-плагин

- **WHEN** выполняется `opencode plugin add ocm991` на хосте v2
- **THEN** пакет установлен и подключён как server-плагин (запись в канонический массив `"plugins"` конфига)

### Requirement: Установка штатной командой хоста

Пакет MUST устанавливаться штатной командой `opencode plugin add ocm991`: команда сама записывает пакет в конфиг, и после перезапуска хоста инструменты памяти доступны в сессии; ручная форма подключения — массив `"plugins"` — допустимая альтернатива.

#### Scenario: Инструменты доступны после установки

- **WHEN** в конфиг без этого плагина выполнен `opencode plugin add ocm991`, затем хост перезапущен
- **THEN** в новой сессии доступны `memory_save` и `memory_list`, конфиг содержит `ocm991` в `"plugins"`

#### Scenario: Одновременное подключение под обоими ключами недопустимо

- **WHEN** пакет уже подключён легаси-ключом `"plugin"` и выполняется `opencode plugin add ocm991`
- **THEN** хост отклоняет установку как дубликат, пока пакет не удалён из легаси-ключа

### Requirement: Обновление штатной командой хоста

Установленный пакет MUST обновляться командой `opencode plugin update ocm991`: команда сверяет установленную версию с реестром и для актуальной версии сообщает об отсутствии обновлений, не меняя ничего.

#### Scenario: Актуальная версия — обновлений нет

- **WHEN** установлена последняя опубликованная версия и выполняется `opencode plugin update ocm991`
- **THEN** команда сообщает, что обновления недоступны, установленная версия не меняется

### Requirement: Поставка без runtime-зависимостей и сборки

Пакет MUST не иметь runtime-зависимостей (поле dependencies) и MUST поставляться без шага сборки: files указывает на исходники, exports ссылается на исходный TS-модуль. Официальный пакет типов API подключается только в форме, не добавляющей runtime-кода: devDependency, импортируемый исключительно как типы.

#### Scenario: Установка не тянет runtime-пакеты

- **WHEN** пакет устанавливается в чистое окружение
- **THEN** runtime-зависимости (dependencies) отсутствуют, транзитивных runtime-пакетов нет

#### Scenario: Entrypoint импортируется без сборки

- **WHEN** хост загружает server-entrypoint из установленного пакета
- **THEN** модуль импортируется напрямую из исходников, шаг сборки перед загрузкой не требуется

### Requirement: Документация установки соответствует механизму хоста

README MUST описывать установку `opencode plugin add ocm991` и обновление `opencode plugin update ocm991` как основной путь, а ручной формой подключения — массив `"plugins"`; легаси-ключ `"plugin"` MUST не рекомендоваться в документации.

#### Scenario: Инструкция воспроизводится буквально

- **WHEN** пользователь выполняет шаги установки из README дословно
- **THEN** плагин подключён штатным механизмом хоста и инструменты памяти доступны в новой сессии

### Requirement: Неизменность поведения памяти

Приведение упаковки к стандарту v2 MUST не менять поведение памяти, зафиксированное в спеках memory-context, memory-storage и memory-tools: форматы хранения, схема памяти, инструменты, fail-open, кросс-процессные локи и редактирование секретов остаются прежними.

#### Scenario: Существующее хранилище продолжает работать

- **WHEN** пакет обновлён или переустановлен через штатные команды хоста
- **THEN** существующее хранилище в каталоге данных пользователя читается без миграции, smoke `memory_save` → `memory_list` проходит, секреты редактируются на входе
