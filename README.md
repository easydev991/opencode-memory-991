# opencode-memory-991

Локальный плагин памяти для [opencode](https://opencode.ai): даёт агенту долговременную память проекта — факты, предпочтения и решения, накопленные в прошлых сессиях, автоматически попадают в контекст новых сессий, а модель может сохранять новое через инструменты `memory_save` / `memory_list`.

Идея агентской памяти не нова — есть несколько похожих систем. Этот плагин отличается от аналогов тем, что:

- **редактирует секреты на входе** — ключи и токены заменяются отпечатком до записи на диск (у большинства аналогов редактирование секретов нет вовсе);
- **хранит память вне репозитория** — в каталоге данных пользователя, а не внутри проекта, откуда её можно случайно закоммитить;
- **защищает записи кросс-процессным локом** — параллельные сессии opencode не затирают друг друга;
- **не даёт модели произвольного кода** — инструменты памяти работают без режима code execution;
- **не имеет ни одной runtime-зависимости и не ходит в сеть**.

Общие черты с аналогами — fail-open хуки, дедупликация фактов, перечитывание снапшота после компакции — в этом плагине реализованы самостоятельно.

Ключевые свойства:

- **Локально и приватно** — памяти хранятся в каталоге данных пользователя, никакой сети и внешних сервисов; секреты (ключи, токены) редактируются на входе и на диск не попадают.
- **Переживает компакцию** — снапшот памяти перечитывается после сжатия контекста, модель не теряет знания в длинных сессиях.
- **Устойчивость к сбоям** — любой сбой хранилища не роняет сессию (fail-open), записи атомарны и защищены кросс-процессным локом.
- **Ноль runtime-зависимостей** — подключается локальным путём в глобальном конфиге opencode.
